# QuitMate 제품 원칙

QuitMate는 사용자가 흡연 욕구를 억지로 참도록 요구하지 않는다. 흡연으로 얻던 즉각적인 만족을
보상, 성취, 걷기 같은 건강한 행동으로 전환해 지속 가능한 금연 습관을 만들도록 돕는다.

## 기능을 제안하거나 구현하기 전

아래 질문에 명확히 답할 수 없다면 기능을 구현하지 않거나 범위를 줄인다.

1. 사용자가 담배를 피우지 않는 행동을 한 번 더 선택하도록 돕는가?
2. 금연 미션 수행, 걷기, 생활 습관 개선 중 하나 이상으로 자연스럽게 이어지는가?
3. 적은 입력과 요청으로 사용자의 핵심 흐름을 지원하는가?
4. 보상이 금연 행동의 결과로 제공되는가?

## 구현 기준

### 금연을 더 어렵게 만들지 않는다

- 불필요한 데이터 입력, 복잡한 상태 전이, 긴 설정 과정을 요구하지 않는다.
- 클라이언트가 다음 행동을 빠르게 안내할 수 있도록 단순한 데이터와 흐름을 제공한다.

### 정보보다 행동 변화를 우선한다

- API와 데이터 모델은 금연 행동, 미션 수행, 걷기, 생활 습관 개선을 지원해야 한다.
- 행동 변화와 무관한 콘텐츠 소비나 기능 탐색을 위한 복잡한 도메인을 추가하지 않는다.

### 보상은 금연 행동을 강화해야 한다

- 보상은 금연 지속, 걷기, 생활 습관 개선 같은 명확한 행동의 결과로만 지급한다.
- 보상 조건, 중복 지급 방지, 상태 전이는 서버에서 일관되게 검증한다.
- 중복 요청, 실패 후 재시도, 부정한 상태 전이도 테스트한다.

### 사용자의 시간을 아낀다

- 화면 구성에 필요한 데이터를 과도한 요청 없이 제공한다.
- 중복 조회, 중복 기록, 불필요한 확인 단계를 줄인다.

### 반복 사용할 핵심 기능을 우선한다

- 팀의 보기 좋은 기능이나 기술 시연보다 금연 성공 가능성을 높이는 경험을 우선한다.
- 사용 빈도와 행동 변화 효과가 낮은 기능은 추가하지 않거나 범위를 줄인다.
