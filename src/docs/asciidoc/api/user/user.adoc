[[user-find-cumulative-change]]
=== 누적 변화 조회

`nonSmokingDays`는 마지막 흡연 날짜부터 오늘까지의 날짜 차이입니다.
흡연 기록이 없으면 금연 시작 날짜를 기준으로 계산합니다.
오늘 흡연하면 0일이며, 캘린더의 누적 금연 성공일 수나 24시간 단위의 경과 일수가 아닙니다.
`totalSmokeFreeDays`는 가입일부터 오늘까지 캘린더에서 금연 성공으로 확인된 날짜 수입니다.
절약 금액과 덜 피운 담배 개비 수는 이 누적일에 현재 설문의 하루 지출액과 흡연량을 각각 곱한 추정치입니다.
설문을 다시 하면 과거 누적 성과도 새 설문 기준으로 재계산됩니다.
